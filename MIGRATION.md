# Golab Serverless Migration

## Overview
This repository originally ran a Go‑based code‑execution service on an EC2 instance exposing a `/run` HTTP endpoint. The service compiles user‑provided Go code inside a Docker compiler container and then executes the binary inside a runtime container, returning stdout, stderr, and execution metrics.

The migration replaces the traditional HTTP server with an AWS Lambda function (`backend/lambda_main.go`) using the **AWS Lambda Go runtime**. The function is invoked via API Gateway (defined in `template.yaml`). All original functionality – size limits, compilation, execution, and response format – is preserved.

## Deployment Steps
1. **Build the Lambda package**
   ```bash
   cd backend
   GOOS=linux GOARCH=amd64 go build -o main lambda_main.go
   zip function.zip main
   ```
2. **Deploy with SAM**
   ```bash
   sam build
   sam deploy --guided
   ```
   The guided deployment will create the API Gateway endpoint `/run`.

3. **Environment Variables**
   - `DEFAULT_COMPILER_IMAGE` – Docker image used for compilation (default `golab-compiler:latest`).
   - `DEFAULT_RUNTIME_IMAGE` – Docker image used for execution (default `golab-runtime:latest`).
   Adjust these in the SAM template or via the Lambda console if you host the images elsewhere (e.g., ECR).

## Local Development
When `LAMBDA_TASK_ROOT` is not set, the binary starts a local HTTP server on port **8080** that mimics the original EC2 behaviour. This allows you to test the service without deploying:
```bash
go run lambda_main.go
curl -X POST http://localhost:8080/run -d '{"code":"package main; func main(){println(\"hi\")}","input":""}'
```

## Security & Scaling
- The Lambda function uses a **global mutex** (`runLock`) to serialize runs, mirroring the EC2 implementation that avoided concurrent Docker container usage. For higher concurrency you can remove the lock and ensure Docker daemon access is safe.
- Timeout is set to **30 seconds** (adjustable in `template.yaml`). Compilation and execution timeouts are enforced inside the function.
